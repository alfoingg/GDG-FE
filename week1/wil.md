# 프론트엔드 찍먹 스터디 1주차 과제
## 강의에서 새롭게 알게 된 내용
**HTML, CSS, JS에 대해 알게 되었다.** 
 - HTML : 웹페이지에 **무엇이 있는지** 적는 언어
 - CSS : 웹페이지에 **어떻게 보일지** 적는 언어
 - JavaScript : **어떻게 동작하는지** 적는 언어
 
 **인스타그램의 하트 예시**
 - HTML : 웹에 하트와 숫자 추가
 - CSS : 하트와 숫자의 크기, 디자인 적용
 - JavaScript : 하트를 눌렀을 때 하트가 빨개지고 숫자가 증가하게 만듦

 **그 외**
  - 이벤트 : 웹에서 일어나는 사용자의 행동
  - DOM(Document Object Model) : 웹페이지의 구조 트리
## 직접 해보면서 알게 된 점
**직접 index.html을 작성하면서 알게된 점**  
기본적인 구조  
\<html>, \<head>, \<body>와 같은 기본 구조로 이루어져 있다.   
추가적인 문법 
- \<h1> : 제목
- \<p> : 문단
- \<ol> : 순서 있는 목록
- \<li> : list item
