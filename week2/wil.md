## 강의에서 새롭게 알게 된 내용
**React** 
 - React : UI를 만들기 위한 도구   
              **React ≠ Programming Language**   
            UI를 만들기 위한 JavaScript Library  



 **JSX**
 - JSX : JavaScript 안에서 UI를 표현하기 위한 문법 


    특징  
        1. HTML과 비슷하게 생김   
        2. {} 이용하여 JavaScript 표현식 사용 가능
